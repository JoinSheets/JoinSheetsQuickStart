title = "5. Save Your Result"
weight = 5
+++

Everything you've configured can be saved as a settings set -- a
**preset**. The current settings are saved automatically, so an
accidental page reload doesn't lose your work; it keeps the settings for
the current session.

To keep your settings across sessions, click **Download Preset** at the
bottom of the **Data** screen. The settings are saved as a separate file
-- you can share it with a colleague, or keep it as one of several saved
views. The **Load Preset** button opens a previously saved settings
file.

{{% tip %}}
The source data is never modified: JoinSheets only reads source files and
never writes to them. So experimenting with settings is always safe --
worst case, you can always go back to the start with the
**Reset to Base** button.
{{% /tip %}}
