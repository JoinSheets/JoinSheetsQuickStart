This step is optional. If you don't configure the fields, the ones you
picked on the previous step are shown as-is.

If the result you want differs from a plain one-to-one display, go to the
field settings via the **Fields** button.

Use the **+ field name** buttons in the **Source Fields (as-is)** block to
add the columns you need, and for each one set a name, data type, and
calculation method: take a source field as-is, reconcile several fields
into one, or compute it with a formula. The row order on this screen
matches the column order in the table you'll see on the next step.
