Нажмите кнопку **«Данные»** в главном меню. В блоке **«Источники и поля»** перечислены все
источники данных, которые видит приложение: с описанием общей информации, числом строк
и моментом актуальности данных.

1. Выберите источники данных, с котрыми Вы собираетесь работать.
   Порядок выбора важен: первый отмеченный источник становится базовым,
   остальные будет присоединяться к нему.
3. Разверните источник кнопкой `+` и отметьте только те поля, которые
   потребуются Вам в работе.
4. Если выбрано больше одного источника данных, ниже появится блок **«Связки между
   источниками»**. В каждой строке выберите тип связки (по умолчанию
   **ЛЕВОЕ**) и поля, по которым будет проходить сопоставление источников —
   их требуется задать явно.
6. При необходимости добавьте **«Условия»** — они ограничивают выборку данных
   и снижают объем рабочего датасета, оптимизируя быстродействие.
